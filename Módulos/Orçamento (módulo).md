# Orçamento (módulo)

Montagem de orçamentos a partir de um catálogo de itens de serviço com valor padrão editável por orçamento, além de itens avulsos criados manualmente para casos fora do catálogo. O orçamento é opcional e pode ser vinculado a uma OS. As regras de situação do orçamento, totais, conversão do orçamento aprovado em OS e as tabelas do módulo serão detalhadas na entrega 2.

## Processos e regras de negócio
- Regras serão detalhadas na entrega 2.

## Requisitos funcionais (7)
- [[RF 4.1]] (Média) — O sistema deve permitir cadastrar item de serviço com nome/descrição e valor padrão
- [[RF 4.2]] (Média) — o catálogo de itens deve ser reutilizável em múltiplos orçamentos
- [[RF 4.3]] (Média) — o sistema deve permitir alterar o valor de um item apenas dentro de um orçamento específico
- [[RF 4.4]] (Média) — a alteração de valor não deve alterar o valor padrão do catálogo geral
- [[RF 4.5]] (Média) — o sistema deve permitir criar item avulso (nome e valor livres) vinculado a um orçamento específico
- [[RF 4.6]] (Média) — o item avulso não deve ser salvo automaticamente no catálogo geral
- [[RF 4.7]] (Média) — o sistema deve permitir vincular, opcionalmente, um orçamento a uma OS.
