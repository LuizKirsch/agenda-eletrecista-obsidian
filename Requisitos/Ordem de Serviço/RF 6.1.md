# RF 6.1

o sistema deve permitir criar uma Ordem de Serviço (OS) informando cliente, endereço, observações e uma ou mais atividades; o cliente é obrigatório e o endereço é opcional; quando informado, o endereço deve pertencer ao cliente da OS (alterado: decisão do projeto);
