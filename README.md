# Agenda do Eletricista — Documentação

Vault do [Obsidian](https://obsidian.md) com a documentação do sistema de agenda e Ordens de Serviço para eletricista autônomo (projeto acadêmico ADS/IENH).

Abra a pasta como vault no Obsidian e comece por **`00 - Visão Geral.md`**.

| Pasta | Conteúdo |
| --- | --- |
| `Módulos/` | Um índice por módulo (Agenda, Atividade, Cliente e Endereço, Orçamento, Usuários e Acesso) |
| `Requisitos/` | Um RF por nota + `Requisitos.base` (tabela filtrável) |
| `Regras de Negócio/` | Processos e suas RNs |
| `Domínio/` | Entidades, relacionamentos e dicionário de dados |
| `Arquitetura/` | Stack, RNFs e decisões |
| `Projeto/` | Contexto, entregas, backlog, histórico de versões |
| `Diagramas/` | Canvas do domínio |

Código do sistema: https://github.com/LuizKirsch/agenda-eletrecista
